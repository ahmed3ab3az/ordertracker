# دليل المستخدم — متتبّع الطلبات

## ١. تسجيل الدخول

شغّل **OrderTracker** من قائمة ابدأ:

* أدخل اسم المستخدم وكلمة المرور.
* اضغط **دخول**.

بعد ٥ محاولات فاشلة متتالية يُغلق الحساب لمدة ٥ دقائق. لإعادة تعيين كلمة
المرور، يستخدم المسؤول شاشة **الشركاء**.

## ٢. النافذة الرئيسية

تتنقّل بين الشاشات من القائمة الجانبية:

* **اللوحة الرئيسية** — مؤشرات اليوم (الطلبات، التسليمات، الأرباح).
* **الطلبات** — الشاشة الأساسية لمسح الباركود واستيراد الإكسل.
* **شركات الإنتاج/التوصيل** — إضافة/تعديل شركاء سلسلة التوريد.
* **الشركاء** — مخصّصة للمسؤول لإنشاء حسابات الشركاء.
* **حصص اليوم** — تسجيل رأس مال كل شريك لذلك اليوم.
* **إغلاق اليوم** — يُنفّذ بعد حسم جميع الطلبات.
* **الإعدادات** — للمسؤول فقط (قاعدة البيانات، اللغة، التحديثات).

تبديل اللغة من شريط القوائم العلوي يُغيّر الواجهة فوراً ويقلب الاتجاه إلى
RTL عند اختيار العربية.

## ٣. استيراد الطلبات

1. **الطلبات → استيراد إكسل**.
2. اختر شركة الإنتاج (PC).
3. يتحقّق التطبيق من الأعمدة المطلوبة (`name`, `address`, `price`).
   عند وجود أي صف غير صالح، يُرفض الملف بالكامل وتظهر الأخطاء بأرقام الصفوف.
4. أكِّد المعاينة. يتم الحفظ بشكل ذرّي وإنشاء باركود لكل طلب.

شكل رقم الطلب: `ORD-PC01-MMDD-NNN`.

## ٤. سير العمل اليومي

1. الاستيراد من إكسل → الطلبات تبدأ بحالة `NEW`.
2. اختر طلب واضغط **تعيين شركة توصيل** → يصبح `ON_HOLD`.
3. في نهاية اليوم استخدم القارئ الباركود:
   * المرتجعات → `RETURNED`.
   * المؤجَّلة → `POSTPONED`.
   * البقية → اضغط **تم التسليم** لتحديدها دفعةً واحدة.
4. من **إغلاق اليوم** يضغط المسؤول **أغلق اليوم**. لا يُسمح بالإغلاق إذا
   تبقّت طلبات `NEW` أو `ON_HOLD`.

بعد الإغلاق، يُسمح فقط بنقل `POSTPONED → ON_HOLD`، أمّا البقية فمغلقة.

## ٥. إعادة الطباعة

اختر الطلب واضغط **إعادة طباعة**. تظهر علامة مائية (`REPRINT`) وتُسجَّل
عملية الطباعة.

## ٦. حصص الشركاء

افتح **حصص اليوم**، اختر التاريخ، وأدخل رأس مال كل شريك. تتحدّث النسب فوراً.
اضغط **حفظ**.

## ٧. الإعدادات

يستطيع المسؤول:

* تحديث رابط قاعدة البيانات (مع اختبار الاتصال قبل الحفظ).
* تغيير اللغة الافتراضية.
* فحص التحديثات.

## ٨. النسخ الاحتياطي والأرشفة

نهاية كل شهر، شغّل أداة الأرشفة على الجهاز الرئيسي:

```
ordertracker-archive --usb-target E:\OrderTracker
```

تُصدّر البيانات القديمة إلى ملف SQLite، تتأكّد من تطابق SHA-256 على فلاش
USB، ثم تحذف الصفوف من قاعدة البيانات السحابية.

## ٩. حل المشاكل

| المشكلة | الحل |
| --- | --- |
| تم قفل الحساب | انتظر ٥ دقائق أو اتصل بالمسؤول |
| رسالة "تم تعديل الطلب من مستخدم آخر" | اضغط تحديث |
| تعذّر إغلاق اليوم | احسم كل الطلبات في `NEW` / `ON_HOLD` |
| فشل التحديث | يُعيد البرنامج الإصدار السابق تلقائياً |
